[Implementation approach]
We will develop a modular Python system that automates the PDDL generation, refinement, and evaluation loop guided by the EW metric, using GPT-4 via OpenAI API for language modeling. The core components include environment API wrappers, prompt generation modules, a PDDL parser and validator, classical planner interface, and a controller orchestrating iterative refinement. Open-source libraries such as 'pyperclip' for handling prompts, 'pddlpy' for parsing/validating PDDL, and 'subprocess' for invoking FastDownward are employed. The system operates as a main script that initializes environment instances, loads NL descriptions, and runs multiple refinement iterations, collecting success metrics.
