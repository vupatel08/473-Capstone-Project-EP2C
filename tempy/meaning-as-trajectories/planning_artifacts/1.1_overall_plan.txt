### I. Overview and Core Concepts

The paper proposes a prompt-free, distribution-based method to extract semantic "meaning representations" from any pre-trained autoregressive language model (LM). These representations are functions over sequences of tokens (trajectories), capturing the distribution of all possible continuations of a given input string. Importantly, this approach:

- Does not require fine-tuning or prompt engineering.
- Enables modeling asymmetric relations (e.g., entailment, hypernym/hyponym) through algebraic operations on likelihood functions.
- Can be extended to multimodal models (text + images).

---

### II. High-Level Methodology

**A. Representation Definition**

For a prompt `s`, define the meaning as:

\[
M_s(t) := P_M(t|s)
\]

which is the likelihood of continuation `t` given `s`. Practically, this is represented as a function over the set of all possible continuations.

**B. Sampling Trajectories**

Since the space of all continuations is infinite, the method:

- Samples a finite set of sequences `T_s = {t_i}` from the distribution `M_s`.
- Uses these samples to approximate distances, relations, and algebraic operations between `M_s` functions.

**C. Distance Metric**

The key measure between two prompts `u` and `v` is:

\[
d(M_u, M_v) \approx \frac{1}{2n} \sum_{t \in T_u \cup T_v} | \log M_u(t) - \log M_v(t) |
\]

where `T_u` and `T_v` are sets of sampled trajectories from each prompt. Sampling uses the LM’s next-token probabilities iteratively.

**D. Operations for Relations**

- **Set-based / Set-theoretic operations:**

  - Intersection (conjunction): approximated via min/minimum over functions.
  
  - Containment: evaluated via entropy or likelihood comparisons, e.g., `M_v <= M_u` if `d(M_u ∧ M_v, M_v)` is small relative to `d(M_u ∧ M_v, M_u)`.

- **Asymmetric relations:**

  - Logical entailment direction inferred via likelihood comparisons on sampled continuations.

**E. Extending to Modalities**

- Use models like LLaVA that process sequences of tokens, whether text or images (encoded as tokens).
- The same sampling and distance procedures are applicable.

### III. Implementation Planning

**A. Model Selection and Loading**

- **Models:** Obtain pre-trained autoregressive models compatible with the method; e.g., GPT-2, GPT-2-XL, LLaMA-13B, Falcon-7B, LLaVA.
- **Implementation tools:** Use HuggingFace transformers library or equivalent accessible API for inference:
  - Generate token probabilities for continuations.
  - Compute sequence likelihoods via product of token probabilities (or sum of log probabilities).
  
- **Considerations:**
  - Loading large models may require significant memory; plan for GPU/TPU availability.
  - For multimodal models such as LLaVA, confirm tokenization processes for images and text.

**B. Trajectory Sampling Procedure**

1. **Input:** String prompt `s`.
2. **Sampling:**
   - Use multinomial sampling with temperature `λ=1.0`.
   - For each trajectory:
     - Initialize with prompt `s`.
     - Iteratively sample next token until:
       - End of sequence token [EOS], OR
       - Max length `m` is reached.
   - Collect `n` trajectories per prompt.
3. **Parameters:**
   - `n` (number of trajectories): 20 (as per paper, can be varied in ablations).
   - `m` (max trajectory length): 20 tokens.
   - Temperature `λ=1.0` for diversity.
   
4. **Sequence probability calculation:**
   - For each trajectory `t = (a_1, a_2, ..., a_m)`, compute:
   
     \[
     \prod_{i=1}^m P(a_i | s, a_1, ..., a_{i-1})
     \]
     
    - Store because this approximates `M_s(t)`.
   
**C. Distance Computation**

- For each pair `(u, v)`:
  1. Sample `T_u`, `T_v` as above.
  2. For each `t` in `T_u ∪ T_v`:
     - Compute or retrieve `log M_u(t)` and `log M_v(t)`.
  3. Approximate:

     \[
     d(M_u, M_v) \approx \frac{1}{2n} \sum_{t} | \log M_u(t) - \log M_v(t) |
     \]

- **Approximate calculation:** Store `\log M_s(t)` during sampling to avoid recomputation.

**D. Relations and Algebraic Operations**

- **Conjunction (intersection):**
  
  \[
  (M_u \wedge M_v)(t) = \min[M_u(t), M_v(t)]
  \]
  
- **Entailment test:**
  
  \[
  \text{If }\; d(M_u \wedge M_v, M_v) < d(M_u \wedge M_v, M_u) \Rightarrow u \Rightarrow v
  \]
  
- **Hyponym test:**
  
  \[
  \text{If } d(M_u \wedge M_v, M_v) < d(M_u \wedge M_v, M_u) \Rightarrow v \text{ hyponym of } u
  \]
  
- Implement these by computing these distances from the sampled trajectories.

**E. Handling of Substring / Context-Conditional Meaning**

- For words or substrings in arbitrary contexts, define:

  \[
  M_u(s, t) = M(s u t)
  \]

- To approximate this:
  - Retrieve text corpora (e.g., Wikipedia, WikiText) containing `u`.
  - Use paragraphs containing `u` as contexts.
  - Sample trajectories starting with these contexts.

**F. Extending to Multimodal Data**

- For models like LLaVA (images + text):
  - Encode images as token sequences.
  - Apply the same sampling process over sequences that start with image tokens.
  - For text prompts, concatenate tokens as usual.
