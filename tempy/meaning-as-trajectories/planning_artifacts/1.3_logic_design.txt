[Logic Analysis]
- ['main.py', 'Entry point; orchestrates configuration loading, dataset initialization, model setup, sampling, evaluation, and logging. Depends on config.yaml for parameters. Calls DatasetLoader, ModelWrapper, Sampler, DistanceEvaluator, and Evaluation.']
- ['dataset_loader.py', 'Handles loading datasets from local files or online sources. Provides methods to get dataset splits, particularly for STS, SNLI, WordNet, and CxC datasets. Supplies sentence pairs or word pairs for evaluation tasks.']
- ['model.py', 'Defines ModelWrapper class, parameterized by model name and device. Handles model loading (from HuggingFace), tokenization, and inference functions: generate_continuations(prompt, n, m, temperature), compute_log_prob(sequence, prompt). Ensures compatibility with text and multimodal models.']
- ['sampling.py', "Contains Sampler class, which manages parallel sampling of trajectories for each prompt in batches. Uses ModelWrapper's generate_continuations, manages max length (m), number of samples (n), temperature. Implements sampling to facilitate multiple trajectories generation, using multiprocessing or threading for speed."]
- ['likelihood.py', 'Contains LikelihoodCalculator class, which uses ModelWrapper to compute sequence log probabilities efficiently, caching where possible. Supports batch computation on multiple sequences.']
- ['distance.py', 'Contains DistanceEvaluator class, which computes the semantic distances and relations between prompts using Monte Carlo estimates from sampled trajectories. Implements the distance formula, conjunction (min), and relation inference algorithms, such as entailment and hyponym detection.']
- ['relation.py', 'Extends DistanceEvaluator to include logic for asymmetric relations (entailment, hypernym/hyponym) based on distance comparisons and set operations. Adds methods for thresholding relation hypotheses and relation directionality decisions.']
- ['evaluation.py', 'Implements function to evaluate on datasets: compute correlation scores (e.g., Spearman) for STS, classification accuracy for SNLI entailment, WordNet hyponym detection, and image-text similarity tasks like CxC. Uses DistanceEvaluator outputs for metrics computation.']
