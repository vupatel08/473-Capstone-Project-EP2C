**Logic Analysis for sampling.py**

---

### Purpose:
`sampling.py` is responsible for generating new images using the trained autoregressive diffusion model. It accommodates both autoregressive (causal) and masked (masked autoregressive, MAR) inference strategies. It executes the reverse diffusion process conditioned on the sequence of tokens generated so far, culminating in decoding tokens into images.

---

### Core Responsibilities:
1. **Load trained models:**
   - The autoregressive Transformer model (with attention mode depending on inference mode).
   - The diffusion denoising head (small MLP).
2. **Implement inference algorithms:**
   - Autoregressive generation: predict tokens sequentially, performing reverse diffusion conditioned on previously generated tokens.
   - Masked (MAR) generation: predict multiple tokens simultaneously with diffusion conditioned on known tokens, progressively reducing masking.
3. **Run reverse diffusion process:**
   - Starting from a noise tensor (`x_T`), iteratively denoise to `x_0`.
   - Condition each step on the current sequence context (`z`) and the diffusion network predictions.
4. **Decode tokens into images:**
   - Use `tokenizer_utils.py` to convert the final token sequence into an image.

---

### Key Components & Functions:

#### 1. Initialization:
- **Model Loading:**
  - Load the trained Transformer model in the specified mode (`causal` for autoregressive, `bidirectional` for MAR).
  - Load the diffusion denoising head (MLP).
- **Diffusion Schedule:**
  - Instantiate the diffusion schedule object with parameters:
    - Number of steps (`sampling.diffusion_steps`, e.g., 100).
    - Noise schedule type: cosine.
  - Precompute `α_t`, `√α_t`, `σ_t` (variance schedule) for each diffusion step.

#### 2. Reverse Diffusion (Sampling) Algorithm:
- **Input:**
  - Optional: initial prompt tokens (`prompt_tokens`) for conditioned generation.
  - Optional: start with noise `x_T` (for unconditional sampling).
- **Procedure:**
  - **Preparation:**
    - Initialize sequence tokens:
      - For causal, start with a seed `[s]` token or the prompt.
      - For MAR, initialize with full masking (all unknown tokens).
    - Initialize `x_T`:
      - If prior info exists, set initial `x_T` from encoded prompt.
      - Else, sample from standard Gaussian `N(0, I)` for each token.
  - **Iterative Denoising:**
    - For `t` in decreasing order from `T` to `1`:
      - If full reverse diffusion, run a denoising step:
        ```
        x_{t-1} = (1/√α_t) * [x_t - (1 - α_t) * εθ(x_t, t, z)] + σ_t * δ
        ```
        where:
          - `εθ` is the denoising network output.
          - `z` is the condition vector, produced by the autoregressive Transformer conditioned on all previously generated tokens.
          - `δ` is Gaussian noise scaled by `σ_t`.
      - For MAR, perform batch prediction over multiple tokens:
        - Identify the unknown tokens (masked positions).
        - Prepare the sequence with known tokens and masks.
        - Compute condition vector `z`.
        - Run diffusion process conditioned on `z` to obtain predicted tokens.
      - **Guidance:**
        - Apply guidance scale (`ω`) on the noise predictions if desired.
        - Scale `εθ` or noise to incorporate classifier-free guidance (using `z_c` and `z_u` if class conditioning is used).
  - **Final step:**
    - After reaching `x_0`, decode the tokens into an image.

#### 3. Handling Different Modes:
- **Causal mode:**
  - Generate tokens sequentially.
  - For each token:
    - Compute `z` conditioned on all previous tokens.
    - Run reverse diffusion to sample the next token.
    - Append to sequence.
- **Masked (MAR) mode:**
  - Use a scheduled masking ratio (from fully masked to unmasked).
  - At each step:
    - Condition on known tokens.
    - Predict multiple unknown tokens simultaneously via diffusion.
    - Update the masking pattern, reducing the mask ratio.
  - Continue until no tokens are masked.

#### 4. Token and Image Handling:
- Use `tokenizer_utils.py`:
  - `decode(tokens)` to translate token sequences into images.
- Input/Output:
  - Inputs:
    - `prompt` (optional): class label or seed tokens.
    - `num_images`: how many images to generate.
  - Outputs:
    - List of images (preferably in base64 or PIL format).
