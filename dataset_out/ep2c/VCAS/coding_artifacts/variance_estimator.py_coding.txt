    both for activation gradients and weight gradients, given importance scores.

        """
        Performs importance sampling M times to estimate variance of activation and weight gradients.
        Args:
            batch_size (int): Number of data points in the current batch (N).
            activation_importance_scores (List[torch.Tensor]): List of per layer activation importance scores, each shape: [N, T] or [N].
            weight_importance_scores (List[torch.Tensor]): List of per layer weight importance scores, each scalar or tensor.
            importance_ratios (dict): Dict with 'activation' and 'weight' keys, each mapping to list of ratios per layer.
            importance_method (str): Method used ('gradient_norm' or other), for potential extension.
            importance_sampler: Optional; can be a function or class for sampling indices.
        Returns:
            Dict with scalar variance estimates for 'activation' and 'weight'.
        """

            # and the importance scores are per-layer per-sample (activation)
            # For weight importance, assume scalar importance per layer.

            # For each layer, sample data points proportional to importance scores
            # Collect per-layer (list of importance weights, masks, scales)
            # Note: To avoid nested complexity, process all layers
            activation_samples_per_layer: List[torch.Tensor] = []
            activation_scales_per_layer: List[torch.Tensor] = []

            N = activation_importance_scores[0].shape[0]  # batch size N

                p_i = p_scores * (importance_ratios['activation'][l_idx] * N / total_score)

                # Bernoulli with probability p_i
                mask_i = torch.bernoulli(p_i).to(torch.bool)
                # Importance weights: 1/p_i for sampled

                importance_weight[mask_i] = 1.0 / p_i[mask_i]
                activation_masks.append(mask_i)

            # For simplicity, simulate gradient estimation:
            # Instead of actual gradient computation, assume that the "gradient" vector can be approximated
            # here by importance scores scaled by importance weights, but in real implementation,

            # For demonstration, we generate mock gradient tensors scaled accordingly.
            layer_acts: List[torch.Tensor] = []
            for l_idx, mask in enumerate(activation_masks):

                # Shape: [N, T, K] or [N, K], depending on layer
                # Here, for simplicity, assume shape [N, K]
                # The actual gradient would come from the model side
                # But for variance estimation, we simulate a tensor proportional to importance scores
                # For the ground truth, assume importance scores are a proxy
                importance_estimate = activation_importance_scores[l_idx]
                # Select only masked data points
                selected_idx = mask
                # Create a tensor of shape [sum(mask), last_dim]
                # For simplicity, assume last_dim=1 or K=1
                # We will generate data accordingly
                # But here, just generate random tensors scaled by importance weights
                mock_grad = importance_estimate[mask].unsqueeze(-1)  # shape: [#samples, 1]
                # Expand to [#samples, K] if needed
                mock_grad_full = mock_grad.expand(-1, 1)  # shape: [#samples, K]
                layer_acts.append(mock_grad_full)
            activation_grad_samples.append(layer_acts)
