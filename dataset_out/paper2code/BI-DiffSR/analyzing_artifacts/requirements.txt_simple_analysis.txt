- Data:

# 2. Model Architecture:
- Class: UNetModel
- Components:
  - ResidualBlock:
    - Implements BinConv (binarized convolution)
    - Includes batch normalization or alternatives as needed.
    - Incorporates timestep embedding (conditional).
  - CPDown (Consistent-Pixel-Downsample):
    - Divides input feature maps along channels into halves.
    - Processes halves with binarized convolutions.
    - Combines via pixel unshuffle (fixed scale factor 2).
      - Ensures consistent dimension reduction and info transfer.
  - CPUp (Consistent-Pixel-Upsample):
    - Uses binarized convolutions.
    - Concatenates processed features.
    - Applies pixel shuffle for upsampling.
  - Channel-Shuffle-Fusion (CS-Fusion):
    - Splits input features into odd/even channels.
    - Shuffles channels and then concatenates paired features.
    - Applies two binarized convolutions.
    - Produces fused features with balanced value ranges.
  - Timestep encoding:
    - Generates sinusoidal positional embeddings for timestep t.
@ Uses standard positional encoding formulas.
  - Modules TaR and TaA:
    - For each, instantiate K=5 pairs of learnable bias vectors and RPReLU modules.
    - Based on timestep t, select corresponding bias and activation group.
    - TaR: adds bias to input features to shift activation distributions.
    - TaA: applies selected RPReLU module to adjust output activations.
- Interfaces:
  - forward(input, timestep_embedding, condition) -> noise prediction tensor.
  - connect with diffusion process and training routine.
- Binarized convolution:
  - Weights scaled by mean absolute value.
  - Binary weights obtained via sign of scaled weights.
  - Activation:
    - Sign function with learnable bias.
    - Straight-through estimator for training.
- Activation functions:
  - RPReLU:
    - Learnable scale and shift.
    - Differ for each bias/activation pair in TaR and TaA.

# 3. Binarization details:
- Class: BinarizedConv
- Operations:
  - Binarize weights:
    - scaled: w_b = mean(|w_f|) * sign(w_f)
  - Binarize activations:
    - use sign(x + bias), with bias being learnable parameters.
    - STE used in backpropagation.
  - Convolution:
    - Implement using efficient bitwise logic (XNOR + bitcount).
- Connection:
  - Use in residual blocks, CP modules, fusion modules.

# 4. Diffusion Process:
- Class: DiffusionSampler
- Initialization:
  - Uses trained UNet model.
  - Parameters: total_timesteps=2000, inference_timesteps=50.
  - Diffusion schedule: linear or cosine (consistent with standard diffusion training).
- Sampling:
  - Implements DDIM sampler:
    - input conditioned on LR image.
    - iterative denoising starting from Gaussian noise.
    - perform 50 inference steps.
- Forward pass:
  - At each step t, predict noise epsilon_t.
  - Use schedule, with timesteps, to update the noisy image.
- During training:
  - Add noise to HR images according to timestep schedule.
  - Model predicts noise conditioned on LR image and timestep embedding.

# 5. Training loop:
- Setup:
  - Optimizer: Adam with lr=1e-4, betas=[0.9, 0.99].
  - Total iterations: 1 million.
  - Batch size: 16.
  - Loss: L1 between predicted noise and true noise.
- Procedure:
  - For each batch:
    - Load LR and HR images.
    - Generate timestep t randomly between 1 and 2000.
    - Compute noisy input:
      - add noise: x_t = sqrt(alpha_cumprod_t)*x_0 + sqrt(1 - alpha_cumprod_t)*noise
    - Get timestep embedding with sinusoidal positional encoding.
    - Forward:
      - Run through UNet with TaR/TaA modules.
    - Compute loss and backpropagate.
  - Update parameters.
