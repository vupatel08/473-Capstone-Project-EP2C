[Logic Analysis]
- ['dataset_loader.py', 'Defines Dataset class to load and preprocess DIV2K images, including normalization and augmentation if training from scratch. Implements functions to load images, provide indexing, and return image arrays as NumPy ndarrays.']
- ['model.py', 'Contains neural network classes for implemented super-resolution architectures like EDSR, RCAN, SwinIR. Implements loading pretrained weights or training from scratch. Includes a function to generate the impulse response by feeding an impulse image through the model.']
- ['signal_analysis.py', 'Provides functions to perform Fourier transforms, spectra analysis, and spectral spectrum comparison. Implements extraction of impulse responses, decomposition of network output into linear and nonlinear parts, and FSDS metric calculation.']
- ['evaluation.py', 'Provides functions to compute PSNR, SSIM, LPIPS, and FSDS between HR and SR images. Includes functions to visualize spectra, impulse responses, and spectral similarity plots.']
- ['main.py', 'Serves as the entry point orchestrating dataset loading, model inference, spectral analysis, and visualization. Coordinates execution order: load data -> load models -> generate impulse responses -> spectral analyses -> evaluate metrics -> visualize results.']
- ['utils.py', 'Contains utility functions such as spectral normalization, spectral plotting, spectral similarity calculation, convolution operations, and helper functions to ensure code modularity.']
