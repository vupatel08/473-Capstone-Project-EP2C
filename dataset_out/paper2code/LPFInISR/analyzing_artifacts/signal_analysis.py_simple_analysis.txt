# Logic Analysis for signal_analysis.py

This script serves as the computational core for spectral analysis, impulse response extraction, response decomposition, and FSDS metric calculation. Its functions must accurately implement the signal processing operations described in the paper to enable faithful reproduction of the experiments. The following analysis details the necessary functions, their inputs and outputs, the core algorithms, and considerations for alignment with the paper and configuration.

---

## 1. Fourier Transform Functions

### 1.1. compute_fft(image: np.ndarray) -> np.ndarray
- **Purpose:** Compute the 2D Fourier spectrum of an image.
- **Inputs:**
  - `image`: 2D (grayscale) or 3D (color channels) NumPy array representing the image.
- **Implementation Details:**
  - Use `np.fft.fft2()` with parameters:
    - `fft_size` from configuration (e.g., 256), zero-padding if image size is smaller.
    - Apply window function (e.g., Hann) if spectral normalization is enabled.
  - Shift the zero frequency component to the center with `np.fft.fftshift()`.
- **Outputs:**
  - Complex spectrum `np.ndarray` of shape `(fft_size, fft_size)` (for each channel if color).
- **Notes:**
  - Normalize pixel values to the range expected by the analysis (e.g., [0,1]) or log-scale as needed.
  - Handle multi-channel images (RGB) by processing channels separately or averaging.

---

### 1.2. normalize_spectrum(spectrum: np.ndarray) -> np.ndarray
- **Purpose:** Normalize the spectrum for spectral comparison.
- **Inputs:**
  - `spectrum`: complex spectrum array.
- **Implementation Details:**
  - Subtract mean, divide by standard deviation (per spectrum).
  - Optional: apply a windowing function if not applied during compute_fft.
- **Outputs:**
  - Normalized spectrum array.
- **Notes:** 
  - Ensures spectral features are comparable across images and experiments.

## 2. Impulse Response Extraction

### 2.1. extract_impulse_response(model: torch.nn.Module, device: torch.device) -> np.ndarray
- **Purpose:** Generate the impulse response of the trained network's linear component (H(δ)).
- **Inputs:**
  - `model`: The trained super-resolution model.
  - `device`: Computation device (CPU/GPU).
- **Implementation Details:**
  - Create an impulse image: e.g., an array of shape `(image_size, image_size)` with a single pixel set to maximum value (e.g., 1.0 or 255), others zero.
  - Convert the impulse image to a torch tensor, move to device.
  - Pass the image through the model.
  - Extract the output, convert back to NumPy array.
  - Store the output as the estimated impulse response `H(δ)` in spatial domain.
- **Output:**
  - 2D NumPy array representing the impulse response (H(δ)).
- **Notes:**
  - Perform multiple impulse tests (e.g., in different locations) to verify spatial invariance or collect a mean response.

---

### 2.2. compute_impulse_response(model: torch.nn.Module, image_size: int, device: torch.device) -> np.ndarray
- **Purpose:** General interface to get impulse response for any model via a synthetic impulse.
- **Implementation:**
  - Generate impulse image.
  - Forward through model.
  - Return the output as an impulse response.

## 3. Response Decomposition (H(I) and G(I))

### 3.1. decompose_response(network_output: np.ndarray, impulse_response: np.ndarray) -> Tuple[np.ndarray, np.ndarray]
- **Purpose:** Separate the network output into linear and nonlinear responses.
- **Inputs:**
  - `network_output`: full model output `N(I)` for a given input.
  - `impulse_response`: `H(δ)` obtained from previous function.
- **Implementation Details:**
  - **Estimate H(I):**
    - Convolve the impulse response `H(δ)` with the impulse input (or directly with the impulse image).
    - For generalized input, approximate as convolution:
      - If the input is the impulse image, `H(I)` can be approximated by convolving `H(δ)` with the impulse pattern, then upsample (if needed).
    - Alternatively, for each `N(I)`:
      - Compute `H(I) = convolution of H(δ) with I`, which reduces to simple convolution if input is impulse.
  - **Obtain G(I):**
    - `G(I) = N(I) - H(I)`
- **Outputs:**
  - `H(I)`: linear response.
  - `G(I)`: residual nonlinear response.
- **Notes:**
  - For a synthetic impulse input, direct convolution recovery is straightforward.
  - For actual images, response decomposition involves subtracting estimated linear part from the network output.

## 4. Spectral Analysis of Responses

### 4.1. compute_spectrum(image: np.ndarray) -> np.ndarray
- **Purpose:** Compute power spectrum of an image or response.
- **Implementation:**
  - Use `compute_fft()` to get spectrum.
  - Calculate magnitude: `np.abs()`.
  - Square to get power spectrum.
  - Return power spectrum for comparison.
- **Notes:**
  - For high-frequency injection analysis, focus on regions outside the spectrum center.

### 4.2. spectral_similarity(
  spectrum1: np.ndarray,
  spectrum2: np.ndarray
) -> float
- **Purpose:** Compute similarity (e.g., FSDS) between spectra.
- **Implementation:**
  - Use the formula for FSDS:
    - Normalize spectrums (subtract mean, divide by std).
    - Compute difference `D = |D(HR) - D(SR)|` (element-wise).
    - Sum all elements, take `log10()` as per paper.
  - Alternatively, implement as per detailed formula in the paper.
- **Outputs:**
  - Scalar FSDS score indicating spectral similarity.

## 5. FSDS Metric Calculation

### 5.1. calculate_fsds(
  hr_image: np.ndarray,
  sr_image: np.ndarray,
  fft_size: int,
  window: str,
  normalize_spectra: bool
) -> float
- **Purpose:** Compute FSDS between HR and SR images.
- **Implementation:**
  - Compute FFT of both images using `compute_fft()`, with `fft_size`, `window`.
  - Normalize spectra if enabled.
  - Compute the power spectral density (PSD): magnitude squared.
  - Calculate `D(HR)` and `D(SR)` (spectral distributions).
  - Compute `D_diff = |D(HR) - D(SR)|`.
  - Sum over all points, take the logarithm.
  - Return scalar FSDS.
- **Notes:**
  - Ensure normalization as per the paper to maintain consistency.
  - Consistent spectral windowing and size are crucial.
