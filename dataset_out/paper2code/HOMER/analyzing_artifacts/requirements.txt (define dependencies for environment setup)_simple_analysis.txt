# requirements.txt (define dependencies for environment setup)

This dependencies list ensures the environment aligns with the technical requirements described in the paper, the implementation plan, and the JSON-based design, enabling accurate reproduction of the HOMER methodology.

---

**1. Main Deep Learning Framework**

- **torch==1.13.1**  
  *Rationale:* Essential for tensor operations, model inference, and custom kernel functions. The paper emphasizes efficient GPU inference with FlashAttention, which relies on PyTorch.

- **transformers==4.31.0**  
  *Rationale:* Provides pretrained language models (e.g., Llama-2), tokenizer interfaces, and layer access. Critical for loading the model, extracting attention weights, and running inference segments.

**2. Numerical and Mathematical Utilities**

- **numpy==1.21.0**  
  *Rationale:* Needed for sequence manipulations, statistical calculations, (e.g., attention importance scores calibration), and array operations.

- **scipy==1.10.0**  
  *Rationale:* Provides additional statistical functions, optimization routines for calibration, and other numerical utilities that might be necessary for token importance calibration and evaluation.

**3. Progress and Logging**

- **tqdm==4.65.0**  
  *Rationale:* For progress bars during long data loading, processing, and iterative merging steps, critical for monitoring during experiments.

---

**4. Hardware Compatibility and Performance**

- No additional dependencies are specified for hardware acceleration beyond PyTorch with CUDA support and FlashAttention, which is included with appropriate PyTorch versions.

---

**5. Optional / Supporting Packages**

- No additional packages are needed for core functionality, but optional extensions may include:

  - **sentencepiece (if used for tokenization, though transformers generally handle this)**
  - **pyyaml (for config file parsing)** — often used but may be handled via standard Python YAML libraries if scripting.

---

**Summary:**

| Package                  | Version   | Purpose                                                         |
|--------------------------|-----------|-----------------------------------------------------------------|
| torch                    | 1.13.1   | Deep learning, model inference, attention kernels               |
| transformers             | 4.31.0   | Model and tokenizer loading, layer access, inference segmentation|
| numpy                    | 1.21.0   | Numerical operations, calibration calculations                   |
| scipy                    | 1.10.0   | Optimization, statistical functions for calibration              |
| tqdm                     | 4.65.0   | Progress visualization during recursive merging and evaluation   |

---

**Note:** Ensure that the environment supports CUDA with suitable driver versions compatible with torch 1.13.1, and that FlashAttention (Dao, 2023) is installed and compatible with the PyTorch version for GPU acceleration.

---

This setup will facilitate the implementation of the hierarchical merging algorithm, attention-based token pruning, efficient memory utilization via the DFS traversal, calibration procedures, and evaluation metrics as described in the paper and plan.
