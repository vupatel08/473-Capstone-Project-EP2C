[Logic Analysis]
- ['dataset_loader.py', 'Defines DatasetLoader class that loads datasets, generates prompt-response pairs, scores responses with detectors, and constructs preference pairs. It depends on detector.py for scoring. Loads datasets such as OpenWebText, instruction datasets, and API responses for detectors.']
- ['detector.py', 'Provides Detector class to interface with open-source models (e.g., RoBERTa) and APIs (e.g., GPTZero). Implements score_response(prompt, response) and batch_score() methods for detector scoring, storing API keys if required, handling response calls, and consolidating scores.']
- ['model.py', 'Defines Model class, loads HuggingFace models (Llama-2-7B, 13B, or Chat variants). Implements generate() (for text generation), log_probability() (to compute sequence probabilities), save() and load() for checkpoints. Depends on transformers and torch.']
- ['trainer.py', 'Contains Trainer class implementing DPO fine-tuning. Uses dataset_loader.py for data, model.py for model, and detector.py for scoring. Implements train() method with the DPO loss (including KL regularization) and hyperparameters like beta, lr, epochs.']
- ['evaluation.py', 'Provides Evaluation class to measure AUROC, perplexity, transferability, and human evaluation metrics. Uses detector.py for scoring, and implements methods for evaluation over validation sets and cross-detector tests.']
- ['main.py', 'Main entry point coordinating configuration, dataset loading, model training, and evaluation. Manages flow control, hyperparameters, and logging. Calls functions/classes from all modules to execute the experimental pipeline.']
