[Implementation approach]
We will develop a modular Python system leveraging open-source libraries such as PyTorch for model implementation, Hugging Face Transformers for core architectures, and existing tokenizers from the LDM repository. The main components include data loading and preprocessing, tokenization, a Transformer-based autoregressive model with causal and masked attention modes, a small MLP denoising diffusion head, training and sampling routines for diffusion, and evaluation metrics. The design emphasizes simplicity, reusability, and clarity, allowing straightforward extension or modification.

        +__init__(config: dict)
        +forward(tokens: Tensor, mask: Optional[Tensor]=None, condition: Optional[Tensor]=None) -> Tensor
        +get_condition(tokens: Tensor) -> Tensor
        +set_mode(causal: bool)

    class DiffusionHead {
        +__init__(input_dim: int)
        +predict_noise(x_t: Tensor, t: Tensor, condition: Tensor) -> Tensor
    }
    class DiffusionScheduler {
        +__init__(num_steps: int)
        +get_noisy_sample(x: Tensor, t: int, noise: Tensor) -> Tensor
        +sample_reverse(x_T: Tensor, condition: Tensor) -> Tensor
    }
    class Trainer {
        +__init__(model: TransformerModel, diffusion: DiffusionHead, scheduler: DiffusionScheduler, dataset: DatasetLoader, config: dict)
        +train() -> None
        +save_checkpoint(path: str) -> None
        +load_checkpoint(path: str) -> None
    }
    class Sampler {
        +__init__(model: TransformerModel, diffusion: DiffusionHead, scheduler: DiffusionScheduler, config: dict)
